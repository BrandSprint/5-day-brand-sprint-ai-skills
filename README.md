# BrandSprint plugin marketplace

Private marketplace for the BrandSprint AI Skills plugin.

In Cowork: Customize › Plugins › Add › Add marketplace, paste this repository's URL, then install **brandsprint**.

In Claude Code: `claude plugin marketplace add brandsprint/5-day-brand-sprint-ai-skills`, then `claude plugin install brandsprint@brandsprint`.

The plugin lives in `plugins/brandsprint/`.
